# Product

## Register

product

## Users

Linux users who want to practice touch typing without leaving the terminal.\
They value keyboard-driven tools, low setup cost, and short focused sessions.

## Product Purpose

Keygraphy is a minimal terminal typing tutor. It measures accuracy and latency\
per key, keeps each lesson focused on the least confident unmastered key, and\
introduces letters, capitals, and punctuation as their best smoothed speed\
reaches the target.

## Brand Personality

Focused, quiet, precise. The interface should disappear behind the act of\
typing and provide immediate, legible feedback.

## Design Principles

1. Start typing immediately.

2. Show only information that changes the current practice session.

3. Make progress visible without interrupting flow.

4. Work with the user's terminal theme rather than replacing it.

5. Keep data local and understandable.

## Accessibility & Inclusion

Never communicate correctness through color alone. Preserve terminal defaults,\
support Unicode input, remain usable without mouse input, and provide a clear\
message when the terminal is too small.
